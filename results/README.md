# Results and evidence

`empirical-2026-10-16/` contains the [independent numerical validation report](empirical-2026-10-16/REPORT.md), [PDF](empirical-2026-10-16/validation_report.pdf), complete aggregate data, figures, and provenance. It adds channel-level and cooling checks beyond the scalar baseline, and records limitations and recommended prose corrections. Finite simulations are not a proof of the universal memory theorem.

`table1/` contains the committed numerical baseline generated by `scripts/reproduce_table1.py`. Its CSV and JSON metadata reproduce the majority-refresh example at `q=0.9`; tests compare the readable-lifetime and conservative-guarantee integers against Table I of the supplied manuscript.

This is an independent implementation of the stated equations. It is not the manuscript's original supplement and does not establish the general contraction theorem, physical circuit correctness, cooling-noise construction, or task-learning guarantee.

Use ignored `results/local/` for exploratory or large runs. Promote a result into a versioned subdirectory only with its parameters, execution command, provenance and a short interpretation. Do not overwrite a baseline with a different scientific configuration without updating its documentation.
