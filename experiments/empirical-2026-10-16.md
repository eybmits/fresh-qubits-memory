# Numerical validation protocol, 16 October 2026

Scope: current manuscript, `paper/source/memory_limits.tex`, revision 3. Numerical experiments, not hardware evidence or a proof of a universal theorem. Protocol written before running the experiments. No change to manuscript claims or scientific source.

Run `MPLCONFIGDIR=work/mpl-cache OPENBLAS_NUM_THREADS=1 python3 scripts/validate_empirical.py --output-dir results/empirical-2026-10-16`. Optional dependencies are NumPy, SciPy, and Matplotlib; the original runtime remains standard-library only. Master seed: 20261016; separate deterministic child seeds per experiment. Float64 / complex128 except the existing exact-rational reference implementation. Store software versions, source hashes, grids, seeds, timings, and all aggregate rows. Do not discard unfavorable observations.

1. **Complete majority channel.** Enumerate the reversible basis map in Eq. (12) for r = 1, 3, 5, 7 (n = 4, 8, 12, 16). Check bijectivity, independently implement compute-then-swap, and propagate the complete diagonal probability distribution through discard/prepare, permutation, and independent physical noise. Check q = 0.5, 0.7, 0.9, both writes, mixed initial states, and 30 hold cycles. Compare one-qubit Z to Eq. (14). Relative/absolute numerical tolerances 1e-10. The diagonal simulation is exact for this construction, up to floating point.
2. **Physical sampling.** Draw one million independent r-bit error patterns for each odd r from 1 through 15 at q = 0.9. Count actual majority failures; report exact two-sided 99% Clopper-Pearson intervals and transform them to continuous half-life intervals. A zero count supplies only an upper bound on error probability; never claim an infinite lifetime. The intervals are pointwise, not a simultaneous 99% statement. Separately run 12,000 complete 32-bit trajectories with the same total n, r = 1, 3, 5, through twice their reference half-life. Report pointwise 95% binomial intervals for the measured first memory bit. Formula predictions are held out from the state update.
3. **Size controls.** Compare active repair with optimally decoded passive repetition, using an explicitly labeled difference of observables. A fixed-k cyclic shift reservoir gives a pulse-memory witness as n varies. This can improve below a size-independent ceiling; do not interpret the theorem as equality across architectures. Passive distinguishability is exact total variation of two binomial distributions.
4. **Genuinely quantum small systems.** Complex density matrices, Haar-random fixed unitaries, nonorthogonal input states, n = 2..5, k = 1 or 2 with k < n, q = 0.5 or 0.9, four unitaries per setting. Verify discard/prepare with independent Kraus operations. Warm two extremal initial states with identical random inputs until their trace distance is <1e-12 (cap 400 cycles). Then insert differing inputs and a common 40-input suffix. Record trace distances, normalized purities, the purity-recursion ratios, and the common-norm contraction. These sampled histories are not the supremum defining W. Separately test the one-step contraction for random traceless Hermitian operators. Allow numerical slack 1e-10 and record maxima, not just pass/fail.
5. **Noise controls.** Complete diagonal majority-channel simulation with extra independent bit flips, full depolarization, and dephasing without a depolarizing core. Check that an additional unital channel can destroy attainable memory while preserving the universal upper bound. For time-correlated errors enumerate the fixed error ensemble and verify two-cycle revival; this is outside the Markovian hypothesis.
6. **Cooling construction.** Simulate Appendix C with exact block-count Markov dynamics, preserving correlations between all blocks. This is an exact reduction of the diagonal bit process, not the paper's scalar majority recurrence. Two reset control qubits, q = 0.9, gamma = 0.3, s = 4, r = 3, 7, 15, 31, 63, 127; 3,000 trajectories per stored bit, 600 hold cycles. Start from the exact stationary echo state for an infinite all-store-zero prefix: independent Bernoulli p* bits. Rotate blocks, apply XOR from the active block's threshold, then sample each physical 0->1 and 1->1 transition via independent binomials. Compare decoding gaps with the union bound where nonvacuous. Add gamma = 0 control, whose corresponding echo state is maximally mixed. Right-censor lifetimes beyond the simulation horizon; finite grids do not establish asymptotic scaling. Independently test count-transition distributions against explicit bits on small registers.

Acceptance: deterministic small-system identities and bounds must hold within stated tolerance. Statistical observations carry intervals; a miss triggers inspection, not seed changes. An observed counterexample to a blanket prose claim is recorded separately from the mathematical theorem. No claim of novelty, quantum advantage, gate-level reliability, or hardware validation follows.
