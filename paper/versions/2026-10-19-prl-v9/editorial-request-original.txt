2. SM Sec. III G, am Ende (nimmt die Zahlen auf)
The gap is large in absolute terms. At q = 0.9 and ε = 0.01, the upper bound at k = 5 exceeds 2^470 time steps, while the error-correcting reservoir with k = 5 remembers 316. Both numbers lie on the same exponential scale in k, which is what Theorem 1 asserts; closing the gap between the exponents is an open problem (main text, Conclusion).
3. Intro, Absatz „Known limits on noisy computation …” (ersetzt die Sätze von „Known limits” bis „… so the theorem charges it to the budget”)
Earlier limits on noisy computation bound other resources: the total number of physical qubits for a computation of length T [26], or the gate set, since Clifford circuits forget within polylogarithmic depth however many qubits they reset [27]. Theorem 1 bounds the rate of fresh qubits instead, for any gate set and any number of qubits [28, Sec. VIII B]. Non-unital noise can replace fresh qubits [22], so the theorem charges it to the budget, and it requires a depolarizing component because dephasing alone can preserve a classical bit [28].

Aktuell: „That O(log T) fresh qubits per round suffice to keep a classical bit for T rounds is the repetition code with majority vote [25]. New is the converse: …”
That O(log T) fresh qubits per round suffice to keep a classical bit for T rounds is the repetition code with majority vote [25]. New is the converse, and it is universal: Ω(log T) fresh qubits per time step are necessary for any noisy dynamics, with or without code structure, and neither size nor entanglement nor the choice of unitary can substitute for them [Fig. 3(b)].

At q = 0.9 and ε = 0.01, the memory depth exceeds 300 time steps for k = 5 and two million for k = 15: every two additional input qubits multiply it by more than five [28, Table S1]. The same copies without the majority vote keep the bit for at most 53 time steps [Fig. 4(b)]; the fresh qubits extend the memory only because the reservoir uses them for repair.
7. Conclusion, erster Satz (etwas schärfer)
The memory of a noisy quantum reservoir is set by its supply of fresh qubits and by whether its dynamics uses them to remove errors, not by its size. Fresh qubits are necessary to reach the memory limit but not sufficient; standard reservoirs, which do not use them for repair, operate far below it.
