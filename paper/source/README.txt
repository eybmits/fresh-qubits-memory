The Memory Limits of Noisy Quantum Reservoirs -- source files

Build (REVTeX 4.2, BibTeX with apsrev4-2):
  pdflatex memory_limits && bibtex memory_limits && pdflatex memory_limits && pdflatex memory_limits
The .bbl file is included for submission systems that do not run BibTeX.

Figures:
  fig1.pdf, fig3.pdf, fig4a.pdf      TikZ schematics; sources in figures/ (compile figN_standalone.tex)
  fig_limit.pdf, fig_repetition.pdf  generated by figures/make_figures.py (matplotlib)

Supplemental Material:
  supplemental_numbers.py reproduces every numerical value quoted in the article (requires mpmath).
