To the Editors of Physical Review Letters

Dear Editors,

Please consider our manuscript, “The Fundamental Memory Ceiling of Noisy Quantum Reservoirs,” by Markus Baumann, Jonas Stein, and Claudia Linnhoff-Popien, for publication as a Letter in Physical Review Letters.

Quantum reservoir computing uses the dynamics of a driven quantum system to process temporal information. Our manuscript addresses a basic resource question: how much input memory can a given supply of fresh qubits sustain under noise, and can increasing the total system size overcome this limitation?

Under local Markovian depolarizing noise, we establish a universal, size-independent upper bound on input memory in the long-time, echo-state regime. At fixed noise strength and a fixed, sufficiently small distinguishability threshold, the optimal memory depth attainable with k qubits refreshed per time step scales as exp[Θ(k)]. The upper bound holds for arbitrary reservoir unitaries and input encodings within the model, without external classical memory or feedback. An explicit reservoir using unitary, measurement-free error correction attains the same exponential scaling. Consequently, Θ(log T) refreshed qubits per time step are necessary and sufficient, in the optimal construction, to retain a past input for T time steps within this setting.

The central physical insight is that entropy removal sets the attainable memory depth. Under the stated noise assumptions, the upper bound depends on input and control operations through their entropy-removal budget. Its scope therefore extends beyond reservoir computing to a broader class of noisy quantum dynamics with a bounded supply of fresh qubits, including measurement-free error correction. The result connects temporal information processing with the resource requirements of error correction and identifies a concrete design objective: the supply of refreshed qubits and the dynamics that use them to protect memory.

This connection between quantum information, open-system dynamics, and physical computing makes the manuscript relevant to the broad readership of Physical Review Letters. It also provides a resource-scaling prediction for experiments using suitable error-correcting reservoir dynamics and mid-circuit resets.

The Supplemental Material contains complete proofs and an exact analysis of the error-correcting construction; simulation code and data are included in the accompanying source archive.
