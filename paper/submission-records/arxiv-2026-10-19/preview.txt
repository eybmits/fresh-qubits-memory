The Fundamental Memory Ceiling of Noisy Quantum Reservoirs
Markus Baumann, Jonas Stein, Claudia Linnhoff-Popien
Fresh qubits, not size, set how long a noisy quantum system can remember. With
k
 input qubits reinitialized per time step, the longest memory any reservoir can attain under depolarizing noise is
exp[Θ(k)]
 time steps, whatever its size, dynamics, and input encoding. A universal upper bound and an explicit reservoir that attains the exponential scaling establish this optimal resource law. The bound depends on the dynamics only through the entropy that fresh qubits remove per time step, so it holds for any Markovian noisy dynamics without feedback, including measurement-free error correction.
Comments:	25 pages, 11 figures, including Supplemental Material. Reproducibility code and data included
License:	http://arxiv.org/licenses/nonexclusive-distrib/1.0/
